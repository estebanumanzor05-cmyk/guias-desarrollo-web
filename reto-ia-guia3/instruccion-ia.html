Reto IA — Guía 3: instrucción, código generado y correcciones

Herramienta de IA utilizada: Gemini (Google) — distinta a ChatGPT (Guía 1) y Claude (Guía 2).

1. Instrucción enviada a la herramienta

Necesito que construyas la página de inicio de un portal de noticias salvadoreño (basado conceptualmente en elsalvador.com), como una nueva versión de un sitio que ya existe. Temática y finalidad: es la página principal de un periódico digital salvadoreño, con secciones de noticias generales, deportes, entretenimiento, turismo, dinero y negocios, y vida. Contenido que debe conservarse: una nota principal destacada, dos o tres notas secundarias, y el menú de navegación con las categorías: Inicio, Noticias, Turismo, Dinero y negocios, Vida, Entretenimiento, Deportes. Identidad visual que debe mantenerse: azul institucional #0f3d63, rojo de acento #d1272f, tipografía serif (Merriweather) para los titulares, y tipografía sans-serif (Inter) para el resto del texto. Requisito obligatorio: la distribución principal de la página (la que organiza la nota principal, las notas secundarias y el resto de la estructura de la página) debe construirse usando CSS Grid (display: grid), no Flexbox ni floats. Puedes usar Flexbox únicamente dentro de componentes aislados, como el menú de navegación o los botones, pero no como el sistema de distribución principal. Formato de entrega: genera el código HTML y el código CSS por separado, en dos bloques distintos (no mezclados en un solo archivo con <style> interno).

2. Revisión del resultado

Gemini conservó la identidad visual pedida (azul #0f3d63, rojo #d1272f, Merriweather/Inter) y sí usó CSS Grid como sistema de distribución principal (.site-container con grid-template-areas, y .hero-grid para la nota principal + sidebar). Sin embargo, no entregó el HTML y el CSS en dos bloques separados como se pidió explícitamente: generó un solo archivo con el CSS dentro de una etiqueta <style> interna.

Al revisar el código también se encontró un error real: en la regla .footer-col h4 aparecía la declaración border-bottom: 1fr solid var(--rojo-acento); — 1fr es una unidad de CSS Grid (fracción del espacio disponible), no una unidad válida para el ancho de un borde, por lo que el navegador ignora esa línea por completo y el borde nunca se dibuja.

3. Cambios realizados sobre el resultado original

  • Separación de archivos: se extrajo todo el contenido de la etiqueta <style> a un archivo independiente css/style.css, y el HTML quedó en index.html enlazándolo con <link rel="stylesheet" href="css/style.css">, cumpliendo el requisito de generación separada.
  • Corrección del borde del footer: se cambió border-bottom: 1fr solid var(--rojo-acento); por border-bottom: 1px solid var(--rojo-acento); en .footer-col h4, para que el borde inferior sí se muestre.

5. Propiedades de CSS Grid presentes en el código

  • grid-template-columns: define el número y el ancho de las columnas. Por ejemplo, en .hero-grid se usa 2fr 1fr para que la columna de noticias ocupe el doble de espacio que la columna del sidebar.
  • grid-template-rows / grid-template-areas: en .site-container se nombran las filas (topbar, header, navbar, main, footer) y cada sección se asigna a su nombre mediante grid-area, en lugar de depender del orden en el HTML.
  • gap: controla la separación entre columnas y filas sin usar márgenes manuales (por ejemplo, gap: 25px en .hero-grid y gap: 15px en .secondary-news-grid).
  • grid-column: 1 / -1: usado en .category-main-card para que esa tarjeta ocupe todo el ancho disponible dentro de su contenedor de 2 columnas, en lugar de quedar en una sola celda.
  • Media queries sobre Grid: en pantallas angostas se redefine grid-template-columns (por ejemplo, .hero-grid pasa de 2 columnas a 1fr), adaptando la distribución sin tocar el HTML.

6. Modificación en vivo (para el video)

Durante el video se debe modificar al menos una propiedad de Grid en las DevTools del navegador. Propuesta: en .secondary-news-grid, cambiar grid-template-columns: repeat(3, 1fr) por repeat(2, 1fr).

Cambio esperado: las tres notas secundarias, que se mostraban en una sola fila de 3 columnas iguales, pasarán a acomodarse en 2 columnas — dos tarjetas en la primera fila y la tercera sola en la segunda fila — porque ahora solo hay 2 pistas de columna disponibles para repartir los 3 elementos.
